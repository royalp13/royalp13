## The sites

**[J&L Trellies & Projects](https://www.jnltrelliesandprojects.co.za/)** — Hammanskraal, live.

They were selling gates off photos in a chat, and quotes that lived in someone's head. Vite, React, TypeScript, Tailwind. 212 photographs of jobs they actually welded, a request for a quote, and an assistant that can start in the customer's language. This is the URL they send. It is not a checkout. A gate is still priced by measuring the opening.

**[The Battlefield Holdings](https://www.thebattlefieldholdings.com/)** — paid, three months, live.

They needed a page the public could open, and an honest note on what was already in the building: CRM, accounting, SharePoint, ERP, written down badly or not at all. I shipped the marketing site. The note stayed a document. I did not invent a platform I was not asked to build.

**[Absa SME / RandPay](https://randpay-smes.onrender.com)** — University of Johannesburg capstone, demo.

An SME loan had to start on a phone and finish where a person could see the application and a score. Python API, a credit-scoring model, React, a database in more than one tier. I was assistant team lead. The score sits in Python so it can be argued with, without the form in the way. It was graded. It is not a job at the bank.

**[Dinnys Freshsphere](https://dinnys-freshsphere.vercel.app)** — Mathibestad, live.

The family kota shop needed an order that was not only a voice note. The React site is small on purpose: a menu, a cart, then WhatsApp, because that is how the shop already talks to people. They use it. WhatsApp still takes orders. I am not going to pretend the site replaced the phone.

**[Thuto](https://thuto-app.vercel.app)** — at home, live.

Built so my siblings could practise English and get homework help they could hear, not only read. Spoken replies. A tool we open in the house. Not a rollout to a school.
